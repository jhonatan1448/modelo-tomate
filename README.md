🍅 Modelo de Fertilización - Tomate

App de Streamlit basada en Modelo Tomate.xlsx: diseño agronómico, requerimientos por etapa fenológica y cálculo de dosis con fertilizantes hidrosolubles.

Pestañas
Diseño del Cultivo: densidad, área, producción y requerimiento del ciclo.
Requerimientos por Etapa: % de cada nutriente en Vegetativo, Desarrollo y Llenado.
Dosis por Etapa: productos y dosis, aportes y % de cumplimiento.
Resumen del Ciclo: totales, cumplimiento y descarga en Excel.
Catálogo de Fertilizantes: composición editable.
Ejecutar localmente
bash
pip install -r requirements.txt
streamlit run app.py
Archivos
app.py — la aplicación
requirements.txt — librerías necesarias
